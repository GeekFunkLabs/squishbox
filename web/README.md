# SquishBox Browser-Based File Manager

> [!NOTE]
> The browser-based file manager is not installed by default and may be
> removed in a future version. The same tasks can be accomplished using
> the built-in `sbcommander` app or plain SFTP, without the disk usage
> and security concerns of installing a web server on the SquishBox.

The optional browser-based file manager installs a web server and
[tinyfilemanager](https://github.com/prasathmani/tinyfilemanager)
on the SquishBox. This makes it possible to edit files and
upload/download/delete content from another device using a web browser.

A username and password for the file manager are set on installation.
Care should be taken not to reveal or lose this password.
